
# SlotLedger — Project Log

## 1. Project goals

SlotLedger is an educational TypeScript application for booking rooms.

Main goals:
- Build a public GitHub portfolio demonstrating practical TypeScript skills.
- Learn how to implement and test business rules.
- Develop automated tests using Vitest and Playwright.
- Create a realistic demo application for the QA Release Check service.
- Eventually prepare a sample QA report based on testing this application.

The project is developed incrementally alongside the owner's full-time QA job.

### TASK 002 — Booking time validation

Status: Completed and committed

Commit:
`e1f0042` — feat: complete booking time validation

File:
- `src/validation/bookingValidator.ts`

Function:
- `timeValidation(startTime: string, endTime: string): boolean`

Requirements:
- Accept time strings in the `HH:mm` format.
- Accept hours from 00 to 23 and minutes from 00 to 59.
- Return `true` only when the end time is later than the start time on the same day.
- Reject equal times, earlier end times and bookings crossing midnight.

Completed:
- Implemented comparison by converting hours and minutes into minutes since midnight.
- Added input-format and time-range validation, according to the completed Codex review.
- Removed temporary `console.log` checks and the temporary import from `main.ts`.
- Ran `npm run build` successfully (reported by Codex and visible in VS Code).

Verification:
- Codex reported TASK 002 implementation ready after review.
- Automated unit tests were subsequently added and verified in TASK 003.
- The correct strict comparison (`<`) was restored after the TASK 003 negative check; the validator matches its committed implementation.
